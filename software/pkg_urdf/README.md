# urdf

Publish URDF robot model

Nodes:
- [georg_description](https://github.com/autonohm/georg_description)
- robot_state_publisher - (mit xacro für macros) urdf publishen

> [!TIP]
> Visualize model and subsystems with [pkg_viz](../pkg_viz/)  
> or manually view the model with `rviz2 -d view_urdf.rviz`

> [!IMPORTANT]
> you need to install and source [georg_description](https://github.com/autonohm/georg_description) to view the robot model,  
> otherwise rviz won't find the robot's 3d model files.
